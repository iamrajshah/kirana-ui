# Kirana owner workflow demo

Open `shopkeeper-workflow-sketch.html` in a browser and use the left navigation
on desktop or the bottom navigation on mobile. The suggested demonstration path
is:

1. Today — show owner priorities and quick actions.
2. Start fast bill — show a walk-in checkout without mandatory customer setup.
3. Pay — show the completed-bill handoff to the next customer.
4. Stock — show low-stock actions.
5. Customers — show balances and ledger-oriented records.
6. Reports & staff — show the owner management workspace.
7. Next phases — explain product ideas that are intentionally not represented as
   production-ready.

The values in the sketch are demonstration data. Screens marked **Implemented**
represent the current UI direction and available product flows. Screens marked
**Planned** require new server, sync, ledger, or external-provider contracts.

The sketch is a standalone demonstration artifact. It does not call the Kirana
API, mutate data, or require Railway/MySQL to be running.
